=====
Unexpected character
=====
( § )
---
L_PAREN "(" @ 1:1
ERROR "§" @ 1:3
error: unexpected character @ 1:3
R_PAREN ")" @ 1:5

=====
Backslash outside a literal
=====
a \ b
---
IDENT "a" @ 1:1
ERROR "\\" @ 1:3
error: unexpected character @ 1:3
IDENT "b" @ 1:5

=====
Unicode escape outside a literal is an error for now
=====
\u0041
---
ERROR "\\" @ 1:1
error: unexpected character @ 1:1
IDENT "u0041" @ 1:2

=====
Lone quote characters
=====
"
'
---
STRING_LITERAL "\"" @ 1:1
error: unterminated string literal @ 1:1
CHAR_LITERAL "'" @ 2:1
error: unterminated character literal @ 2:1
